## 3. 失败查询保留与原因分析

独立留出查询 P1180181 对原40图地图仍被拒绝，产物为 `results/evidence_20261013_holdout0181/`：2,924个对应、613个内点，内点率20.9644%，低于25%门限；内点重投影均值2.1971 px、中位数2.2034 px、P95为3.7384 px，唯一内点关键点604，4×4分区覆盖68.75%。

直接拒绝原因是 `insufficient_pnp_quality` 中的内点比例不足；误差较小只描述已经选中的内点，不能证明其他对应正确。因此没有通过降低门限“修好”该查询。缺少位姿真值和受控标定对照，现有证据不能进一步确定是重复纹理、视角重叠、地图覆盖还是内参偏差主导，也不能证明被拒绝的位姿实际错误。后续应固定标定与参考集合，分别比较检索/匹配分布和带真值的位姿误差。

历史 P1180182 的13.8066%拒绝记录仍保留，但**本轮没有把它重新完整运行**。初次新地图验证目录 `results/increment_validation_20261013/` 也保留：便携 Python 下 coverage CLI 移除了原生扩展搜索路径，导致 `_ctypes` 加载失败；之后改用公共 Coverage API 包装器重新在新目录运行，没有把失败目录改写成成功。
