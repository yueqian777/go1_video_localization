# 可见目标框选修复（2026-10-16）

本次在 `codex/evidence-viser-route-preview`、基线 `f6463a2` 上增量修改。没有接入运动控制、改写地图或调整定位算法，也没有修改原始照片。

## 操作

1. 刷新本地网页，进入“② 找物”，选择目标照片。
2. 点击“打开原图并框选目标”，在照片上直接按住鼠标左键拖动，无需 Shift。
3. 拖动过程中显示绿框，松手后框保留。“框选状态”显示已选中及原图像素尺寸，面板显示带框预览。
4. 拖四角绿色方块调整大小；拖中心蓝块移动。也可以在照片其他位置重画，或者先点“清除选框 / 重新画框”。
5. 确认框后点击“计算目标位置与证据”。状态区分未选择、正在调整、已选中、已提交、完成或失败。

视角发生旋转时重新打开照片可恢复正视角，同一照片的有效选框保留。传统 Shift 拖框继续兼容。手动像素坐标修改与画布框同步。框选不是自动语义分割，输出仍是该区域内的三维证据。

## 实现和防误用

- 原实现只把 Shift 矩形写入坐标，没有持久边框；打开照片又默认采用整张原图。本次移除隐式全图选择。
- 使用已有 Viser 1.1.1 的图片/方块鼠标拖动事件和线段显示，不增加 HTTP 接口或自定义浏览器脚本。
- 图片仅用于显示的缩略尺寸不影响原图坐标。选框限制在原图边界内；反向拖动、角点限位、整框平移均独立处理。
- 选框绑定原图路径、字节 SHA-256 和尺寸。换图、同路径内容改变、文件不可读、非有限数、坐标与显示不一致时不提交。
- 无有效框时禁用计算按钮。拖动开始即使旧目标/路线失效；任务版本校验拒绝旧计算晚到覆盖。多个标签页共享已确认框，过时手势不覆盖更新。
- 拖动回调采用不含 await 的异步回调，按 Viser 事件循环顺序处理起始、更新、结束；以手势起始位置为锚点，不累加已移动把手的位置。
- 换查询、换地图、返回地图时清理对应图片、边框和控制点。重新载入经过验证的对象结果可恢复选框预览。
