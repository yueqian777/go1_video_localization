# Go1 中文地图工作台：快速上手

本轮修改基于 `codex/evidence-viser-route-preview`，沿用现有 Viser、照片证据、原生快照和有向路线规划。没有更换视觉算法、安装环境或接入机器狗运动控制。

## 在这台电脑上打开

双击桌面 **Go1 地图与照片定位**。它使用项目已有 Python 环境，自动打开本地浏览器；重复双击会复用已启动的查看器。

默认查看已有的 30 秒录屏探索地图；页面顶部的“新建地图”现在可以选择 MP4、检查画面后点击按钮实际建图，进度和完成地图都在同页。单纯启动不重新计算，有最近网页建图任务时会恢复监看。启动配置保存在 `.cache/desktop_viewer.json`；结果独立保存在 `results/screen_import_20261014/viewer_zh_20261015/`，旧的 `viewer_v2/` 不覆盖。

默认地址是 `http://127.0.0.1:8767/`。如果端口被其他程序占用，启动器会选择附近空闲端口并打开实际地址，不结束其他服务。实际地址见 `.cache/desktop_viewer.server.json`。

关闭浏览器不会关闭查看器或取消已有后台任务。需要停止本入口启动的查看器时，在项目根目录执行：

```powershell
.\runtime\python312\python.exe -m go1loc.desktop --config .cache/desktop_viewer.json --stop --no-browser
```

启动失败不会修改原地图。查看 `.cache/desktop_viewer.log`；无控制台启动失败时会弹出日志位置。

## 五个步骤

网页一键建图、原尺寸预览、排除区域与按时间播放抽帧，见 [自己建图与图片回放](NEW_VIDEO_AND_PLAYBACK_zh.md)。推荐使用页面顶部“新建地图”，高级命令操作单仅为备用。

| 页签 | 你在这里做什么 | 注意事项 |
| --- | --- | --- |
| ① 地图 | 看最终地图、真实过程快照和历史参考照片 | 不是实时狗的位置；没有点不代表没有障碍 |
| ② 找物 | 选独立目标照片、框选物体、计算三维支持 | 支持点是可见表面的证据，不是完整物体中心 |
| ③ 起点 | 用参考帧设人工历史起点，或定位独立当前照片 | 独立照片还需要合法接入证据，不能自动吸附 |
| ④ 路段 | 生成候选，回看视频，拆分、确认或拒绝，再保存 | 确认历史连续性，不等于现在安全可通行 |
| ⑤ 路线 | 选择已审核路线图与时间模式，计算并导出预览 | 终点是目标观察位置；不是可执行机身或足步路线 |

### 看地图和照片

鼠标拖动旋转，滚轮缩放，视角迷路时点击顶部“恢复地图总览”。

选择历史参考帧后点击“查看参考照片与拍摄位置”，面板会显示照片、文件名和素材显示时间。默认不再强制跳入相机视角；需要时自行勾选“同时进入该相机视角”。所选相机使用粉色线框提示。

根据用户反馈，三维画布不再叠加文字标签，避免遮挡点云。模式、风险和图例保留在右侧面板；蓝色是历史相机，黄色是物体支持点，绿色是观察终点，紫色是待审核候选，青色是路线预览。

### 照片找物

1. 在“② 找物”点击“选择目标照片”，或填写原图路径。
2. 点击“打开原图并框选目标”。
3. **在照片上按住鼠标左键拖出矩形**，无需按 Shift。拖动时可见绿框，松手后保留；“框选状态”显示“已选中”及原图像素尺寸，面板同时显示选框预览。
4. 拖动四角绿色方块调整大小，拖中心蓝块移动。也可在照片的空白位置重新拖框，或点击“清除选框 / 重新画框”；高级坐标输入与可见框同步。重新点击“打开原图并框选目标”可恢复正视角，已有有效选框保留。
5. 确认预览后点击“计算目标位置与证据”。状态依次区分尚未框选、正在调整、已选中、已提交、计算完成/失败。没有有效框不能计算；计算过程中编辑框，旧任务的晚到结果不会覆盖新选择。

坐标始终是原图像素，不是网页缩略图像素。换照片或同路径文件内容变化后必须重新框选，不会把旧框自动套到新照片。原图不会被修改；绿框仅是界面叠加与诊断预览。传统 Shift 拖框仍兼容，但无需依赖它。

选图仅将 PNG/JPEG 原始字节复制到本机结果目录，不上传云端、不修改原图，也不自动提交计算。支持最大 32 MiB、4000 万像素；存储名由内容哈希生成，不使用上传文件名作为路径。重新选目标照片会清除旧目标和旧路线。

掩膜、相机内参、标定与支持点参数位于折叠的高级设置；缺少标定不能编造内参或重复去畸变。正式验证必须使用未参与建图的独立采集照片。

### 人工历史起点与路段审核

先在“① 地图”选参考帧，再到“③ 起点”点击“将选中参考帧设为人工起点”。这是离线实验起点，不是假定机器狗现在位于那里。

在“④ 路段”生成候选，核对原视频以及时间线参考帧。填写审核人与真实依据后，才能确认或拒绝。紫色线不能直接当作通行路线。

**只确认一部分：** 先选首尾帧并拆分；拆出的子段仍待审核，再选对应子段确认。“确认当前整段历史连续”确认的是整段，不是首尾下拉框的局部范围。最后点击“保存审核结果并生成路线图”，路线图路径自动填入“⑤ 路线”。

### 独立当前照片接入与时间

“③ 起点”的进阶折叠区可定位独立当前照片，或载入已有定位结果；另一区提供候选接入节点、证据文件导入、检查及明确采用。检查通过不等于自动采用。来源文件的 SHA256 必须匹配原证据。

时间模式在“⑤ 路线”：真实当前模式保留新鲜度检查；历史回放需另外填写回放参考时间，不能把旧照片拍摄时间改为现在。录屏显示时间不是传感器曝光时间，未知真实采集时间不能伪造。两种模式均保持 `execution_permitted=false`。

## 首次建图监看

原有 `watch-build` 入口保留，面板和主要阶段提示已中文化；仍只加载经过校验的完整 READY 快照。自动跟随、暂停后查看历史、建图失败保留快照等行为不变。

桌面入口默认是已有冻结地图回看，不会替你启动建图。首次建图的监看命令仍是：

```powershell
.\runtime\python312\python.exe -m go1loc.cli watch-build --help
```

## 换地图或重新建立快捷方式

先停止现有桌面查看器，然后在项目根目录执行。参数使用你实际存在的路径；结果目录必须与冻结地图目录分开。

```powershell
.\tools\install_desktop_shortcut.ps1 `
  -MapDirectory '你的冻结地图目录' `
  -SidecarDirectory '独立的界面结果目录' `
  -SnapshotDirectory '可选的快照目录' `
  -Port 8767
```

不使用快照时省略 `-SnapshotDirectory`。安装脚本不下载软件；同名且不属于本项目的快捷方式不会被覆盖。未涉及机器狗网络采集、原始视频或模型权重上传。
