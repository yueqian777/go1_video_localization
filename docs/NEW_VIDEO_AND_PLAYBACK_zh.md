# 自己建一张新地图，以及按视频顺序播放图片

## 直接在网页建图（推荐）

双击桌面“Go1 地图与照片定位”，打开页面顶部 **“新建地图：选视频 → 开始 → 看进度”**。现在不仅可以看旧地图，也能实际启动新视频建图；不需要复制命令。

1. 点击 **① 选择视频 MP4**。原件不动，字节完整复制到本机独立目录；等待原尺寸首帧与尺寸、时长显示。
2. 选对“Go1 界面录屏”或“原始单路视频”。录屏展开 **② 核对单路画面与排除区域**；默认整幅，但必须根据本次实际画面确认。可填保留区域的 x/y/宽/高，添加或撤销多个排除矩形，点击“更新裁剪与有效区域预览”。红色表示不参与特征匹配。
3. 保持未知物理编号、未知投影为空/未知，不编造内参。固定掩膜不能解决移动鼠标、改变窗口布局或动态机身遮挡；这些情况优先重录。原始视频模式保留整幅，不应用录屏裁剪。
4. 默认前 30 秒、每 0.5 秒一张。网页限制单文件 **512 MiB**、单次最多 **240 个候选帧**、最长 **600 秒**。可设置片段起始时间；不是自动处理全部任意长度视频。
5. 勾选已检查首帧，然后点击 **③ 开始建图**。后台实际执行现有抽帧、SuperPoint、LightGlue、PyCOLMAP 流程；无需再启动终端。
6. 同页显示真实阶段、候选/保留帧数及完整快照数量。保持“自动显示最新完整快照”时，画布跟随 READY 快照，成功后自动加载新地图。没有快照时只有阶段提示，不假装显示地图。
7. 完成后可在“① 地图”按时间播放图片，继续照片定位和离线路线审核。也可以暂停跟随、手工查看历史快照，或返回启动时地图（不会取消后台建图）。

默认开启质量过滤；有效帧不足时明确失败并保留质量报告。只有显式勾选“允许低质量探索”才放宽过滤，结果不算正式验收。报告中的连续性风险仍在，不自动生成路线边。无标定的简易入口属于近似几何输入，距离使用 map_units。

后台任务独立于浏览器，刷新或关闭页面不会重启/取消计算；重新打开相同桌面入口会恢复最近的任务。运行期间禁止重复开始或更换视频，参数锁定。每个任务独立保存，失败不覆盖旧结果。此入口没有机器人连接与运动执行。

保存位置显示在“视频任务进度”。启动查看器结果目录下 `web_build/uploads/<id>` 是原字节副本与哈希；`web_build/worker/jobs/<id>` 是任务，含请求、状态、日志以及 `output/prepared`、`output/build_runs`、`output/map`。渲染/查询数据在该任务旁边的 `viewer`，不写入冻结地图。不要删除被清单引用的帧目录。

原有高级操作单仍在“① 地图”中折叠保留，仅供命令行复现，不是网页建图的必要步骤。已有实测标定输入仍使用下面的高级命令入口；本轮不增加自动标定。

完整验证记录见 [网页建图交付记录](WEB_BUILD_VALIDATION_20261015_zh.md)。

## 高级备用：命令行复现

1. 准备新的连续视频。尽量慢速移动、避免跳切，保持同一路相机视图；另拍独立的目标与当前照片，不能拿建图帧当独立查询。
2. 在“① 地图”中展开“高级备用：导出命令操作单”。填入视频完整路径，以及一个**尚不存在的新输出目录**，例如 `D:\Go1Data\hallway_trial_01`。
3. 选择来源：“Go1 界面录屏”或“原始单路视频”，不能把录屏伪装成相机原始码流。录屏还需要先确认裁剪与掩膜配置，见下一节。
4. 默认先处理开头 30 秒，每 0.5 秒取一张，最多 60 张。可以修改时长与间隔；单次上限仍是 600 秒、1000 张。不是默认处理整段任意长度视频。
5. 点击“生成新视频建图操作单”，按面板中的阶段复制命令到 PowerShell。**先抽帧并检查图片与质量报告，再执行建图。** 不要为了得到地图而无条件关闭质量过滤。
6. 建图时另开 PowerShell，运行操作单中的监看命令。`run.json` 出现后即可监看，不需要等待最终地图；默认监看页面为 `http://127.0.0.1:8766/`。
7. 建图成功后运行打开新地图的命令，默认 `http://127.0.0.1:8770/`。这避免与旧查看器的 8767 端口混淆；终端打印的实际地址为准。
8. 想让桌面快捷方式下次默认打开这张新图，就按操作单最后一步先停止旧桌面查看器，再运行快捷方式配置命令。只是改变入口，不删除旧地图。

输出目录中，`prepared` 存抽帧和清单，`map` 存冻结地图，`build_run` 存建图记录与快照，`watcher` / `viewer` 分别存监看与回看结果。每次试验换新目录，不覆盖旧结果。第一次使用大范围视频可能耗时较长；先试片再扩大素材。

## 录屏：先确认单路裁剪，不照抄旧坐标

在项目根目录打开 PowerShell，使用项目已经安装好的 Python，不需要重装 PyTorch/CUDA：

```powershell
.\runtime\python312\python.exe -m go1loc.cli inspect-screen 'D:\你的录屏.mp4' --output 'D:\Go1Data\native_preview_01'
```

打开输出的原尺寸预览，确认实际分辨率、固定单路窗口、十字线、绿色图标、边框等位置。以项目 `configs/screen_652x648_example.json` 为字段示例创建**自己的配置文件**：

- `source_size_wh`、`crop_xywh` 与遮挡区域必须来自这次原尺寸画面，不能依据聊天截图或盲用 652×648 的旧数值。
- `selected_window` 写实际确认的视图，不保留 `EXAMPLE`。
- 物理相机编号未知就保留 `camera_id: null`；没有投影证据就保留 `display_mode: "unknown"`，不重复去畸变。
- `exclude_rectangles` 用原始录屏像素坐标；已有导入器会执行特征排除掩膜，而不是靠把图涂黑。
- `expected_source_sha256` 如果填写，必须是这次原录屏的哈希；旧视频哈希不能用于新录屏。

把配置文件路径填入操作单面板。生成命令不会验证真实视频的全部质量；执行导入时仍会核对实际尺寸、裁剪、来源及 PTS。原始录屏保留不改。未知传感器曝光时间不补成“现在”。

有真实标定的原始单路视频可在生成的 `prepare-video` 命令中追加 `--calibration '实际标定文件.json'`；没有标定时结果属于近似输入，没有米制尺度时仍使用 `map_units`。

## 新增的全程图片播放

刷新查看器，在“① 地图”展开“按视频顺序播放全程图片”：

- **播放全程图片 / 暂停图片播放**：按真实 PTS 时间间隔播放，不压缩缺口。
- **进度滑条**：跳到第几张抽帧，拖动后暂停；这是抽帧序号，不是原视频帧号。
- **上一张 / 下一张 / 从第一张重新播放**。
- **0.5×、1×、2×、4×** 倍速。
- 图片在上方的历史参考照片区显示；面板同时给出源帧号、PTS 和注册状态。
- 粉色相机标记跟随已注册的历史帧；勾选“同时进入该相机视角”时，三维视角也跟随。默认不跳视角。

播放的是这份地图清单中记录的**整段抽帧**，不是重新解码原视频的每一帧，也不是只播放某条规划路线。未注册帧能保留图片但不捏造位姿；缺图时隐藏旧图并提示；质量异常与中断标记继续显示。无序照片或缺失/重复/无效 PTS 时不冒充按时间播放。过程快照只能回放该快照自己的已注册参考子集。

这只是历史画面回放，不自动设置当前位置，不创建通行边，不修改审核结论，也不会驱动机器狗。切换地图或打开目标照片会暂停播放。多个浏览器连接共享同一查看器的播放进度。
