- 本机有 `ffmpeg`/`ffprobe`，没有原生 `colmap` 命令；D 盘 Python 3.12 运行时已经安装 torch、pycolmap、hloc、LightGlue。系统 Python 3.13/3.14 的检查结果不能代表其他未检查环境。
