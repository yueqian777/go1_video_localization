# Go1 采集、建图与视觉定位统一工作台

2026-10-17。在现有功能分支上合并相机录制台与地图查看器，不改动 hloc / SuperPoint / LightGlue / PyCOLMAP，不接入运动程序。

## 现在从哪里打开

本机桌面的 **Go1 采集建图定位工作台** 快捷方式打开统一网页。原录制台与地图快捷方式保留，旧工程和冻结地图不覆盖。工作台默认不连接相机、不录像、不启动导航；点击退出会收尾它自己拥有的采集连接与两个网页服务，不会停止机器狗原厂服务。

网页有两个页签：

- **① 摄像头与录制**：选相机、手动连接、预览、抓拍、开始/停止录像。
- **② 建图 · 定位 · 路线**：现有建图进度、真实快照、目标框选、视觉定位与方向引导。

主页面与 Viser 同属一个启动进程，分别使用本机回环端口；默认从 8772、8773 查找空闲端口。实时定位直接读取采集控制器的源帧，不依赖写死的网页端口，不另开第二条 SSH 连接。

## 录一段，再直接建图

1. 打开采集页，选择实际相机。本机外接 Gemini RGB 对应已有的 camera6 配置；不要套用 camera1 的安装或鱼眼参数。
2. 核对网络和本地 SSH 配置，勾选只读连接确认，再点连接。连接成功只预览，不自动录像。
3. 点击开始录制，由现场人员用自己的遥控器采集；完成后点击停止，等待保存收尾。
4. 顶部“已保存录像”会列出完整真实记录。选择它，点击 **送入建图，检查首帧**。
5. 页面自动切到地图页；展开“新建地图”，核对完整尺寸首帧、相机/投影、标定及时间范围。勾选首帧确认后，点击 **③ 开始建图**。
6. 在同一页面查看阶段和已完整发布的真实快照；完成后查看新冻结地图。

交接只启动素材检查，不替用户确认画面、不自动开始重建。直接使用源 PNG、帧清单和哈希，不需要先导出或再次编码 MP4。未结束、损坏、单张照片或合成色条不列为本流程的真实建图输入。另行上传本地 MP4/MKV 的入口仍保留。

## 用现在的画面定位并给方向

1. 在地图页加载同一环境的冻结地图。首次使用按事实核对地图行走来源和该相机的固定朝前/正立安装设置；不同地图、相机分别保存。
2. 在采集页手动连接相机，确认源画面持续更新。没有有效新画面时，顶部 **使用此相机实时定位** 按钮禁用。
3. 点击该按钮，将同一采集连接设为地图页的当前画面来源。它只选择来源，不自动开始任务。
4. 选择目标照片，用鼠标框选并计算目标，取得成功的地图几何支持。随后点击 **开始方向引导（不控制机器狗）**。
5. 系统取源图，使用既有定位器计算相机在地图中的位置/朝向，再关联历史路段、路口连接及目标观察位姿，显示路线、方向与下一参考画面。现场人员自行决定是否遥控行走。
6. 暂停、取消或断开相机后，旧的当前位置和方向不能继续冒充当前结果。换相机或采集会话后须重新开始任务。

顶部“当前源帧已定位”只在有有效实时结果时出现；旧目标照片、历史地图相机和独立录像回放都不当作实时位置。位置更新由实际完成的照片定位推进，不按动画时间推移。下一帧会采用最新源图，避免积压待处理帧。

### 位置和时间的边界

- 这里得到的是**地图坐标系中的相机位姿估计**，不是 GPS、机身真值或脚步位置。没有外参就不能把相机中心等同机身中心；没有米制尺度仍显示 `map_units`。
- 不保证每个摄像头帧都完成定位。更新速度依赖实际特征匹配与求解耗时；界面显示计算延迟，过期结果撤销引导。
- 记录源会话、相机号、源帧序号、原始接收单调时刻、板端读取时刻和 PNG 哈希。保存图片/完成计算时刻不会改写成曝光时刻。
- `sensor_capture_time=null`、`sensor_freshness=unverified`。收到包不证明新的曝光；完全相同画面可能是静止或冻结，不据此虚构运动进度。
- 摄像头断开、疑似冻结、源格式/会话变化会拒绝当前输入；后台旧计算结果不会恢复旧路线。
- 此轮没有机器人执行、避障闭环或自由空间规划，所有结果保持 `execution_permitted=false`。历史路线重组仍受已有几何证据与方向规则约束。

## 启动与移植（高级用法）

在项目根目录运行，使用已有视觉环境，不要为合并重装 CUDA/PyTorch：

```powershell
.\runtime\python312\python.exe -m go1loc.workbench --config data/workbench/launcher.json
.\runtime\python312\python.exe -m go1loc.workbench --config data/workbench/launcher.json --stop --no-browser
.\tools\install_workbench_shortcut.ps1 -VerifyOnly
```

其他已有配置环境可使用 `python -m go1loc.workbench`，安装包入口为 `go1-workbench`。

可移植模板为 `configs/workbench.example.json`。连接配置仍使用原录制台的结构，示例见 `configs/capture_go1.example.json`；示例地址/代理路径不是当前设备已验证的连接信息，主机指纹与认证需自行核对。密码、私钥不写进网页或公共仓库。

工作台要求录像根目录为本项目 `data/captures`，与现有素材目录一致；其他目录会明确报错，不默默忽略。不自动搬动旧录像。`viewer_config=null` 时从无地图页面启动，可以先录像或上传视频再建第一张地图，无须假造 `map_manifest.json`。

`viewer_config` 可指向既有桌面查看器配置格式（`map_dir`、`sidecar_dir`、可选 `snapshot_dir`）；修改结果写到独立 sidecar，不能覆盖冻结地图。工作台退出后重新启动复用本地设置，但不会自动连接、续录或执行旧的导航任务。
